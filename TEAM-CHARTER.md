## 10. Decision-Making

When we disagree, we will:

1. Explain the tradeoff clearly
2. Consider user value and project goals
3. Check the evidence or requirements

## 11. Conflict and Problem Resolution

If a disagreement or problem arises:

- We will raise it early
- We will address it respectfully
- We will focus on the product and the evidence, not personal preference
- We will seek a decision that keeps the project moving forward

## 12. AI Use Expectations

We will use AI responsibly.

- We will verify AI-generated suggestions against the code and requirements
- We will not use AI to hide uncertainty or skip reading the code
- We will document meaningful AI use in the project log
- We will treat AI as a tool, not a replacement for thinking or verification
